# Feature Specification: 背景地図切り替えと出典連動表示

**Feature Branch**: `002-create-feature-branch`  
**Created**: 2026-04-21  
**Status**: Draft  
**Input**: User description: "背景図切り替え機能を画面左下に作成したい。選択できる背景地図はOpenStreetMapと国土地理院の地理院地図と航空写真。表示している背景地図に応じて右下の出典も出しわけること。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 左下で背景地図を切り替える (Priority: P1)

利用者として、画面左下の操作で背景地図をすぐ切り替えたい。そうすることで、同じ地点を複数の地図種別で比較できる。

**Why this priority**: 背景地図の切り替え自体が中核価値であり、これがないと機能要件を満たせないため。

**Independent Test**: 地図画面を開き、左下の切り替えUIから3種類の背景地図を選択して、選択直後に表示が変わることを確認する。

**Acceptance Scenarios**:

1. **Given** 地図画面が表示されている, **When** 利用者が左下の切り替えUIで OpenStreetMap を選択する, **Then** 背景地図が OpenStreetMap に切り替わる。
2. **Given** 地図画面が表示されている, **When** 利用者が左下の切り替えUIで 地理院地図 または 航空写真 を選択する, **Then** 背景地図が選択した種別に切り替わる。

---

### User Story 2 - 右下の出典を背景地図に連動させる (Priority: P1)

利用者として、現在表示中の背景地図に対応した正しい出典を右下で確認したい。そうすることで、地図利用時の情報源を誤認しない。

**Why this priority**: 出典の誤表示は利用規約違反や信頼性低下につながるため、切り替え機能と同等に重要。

**Independent Test**: 各背景地図に切り替えた時、右下表示が対応する出典文言へ即時更新されることを確認する。

**Acceptance Scenarios**:

1. **Given** OpenStreetMap を表示中, **When** 利用者が背景地図を地理院地図へ切り替える, **Then** 右下の出典が地理院地図向けの文言に更新される。
2. **Given** 地理院地図または航空写真を表示中, **When** 別の背景地図へ切り替える, **Then** 右下の出典が選択中背景地図に一致する文言へ更新される。

---

### User Story 3 - 初期表示時にも出典整合を保つ (Priority: P2)

利用者として、初期表示時点でも背景地図と出典が一致していてほしい。そうすることで、切り替え前から正しい情報源を確認できる。

**Why this priority**: 切り替え操作後だけでなく初期状態の整合性も、品質と信頼性の要件として必要。

**Independent Test**: 画面初期表示時に、実際に表示されている背景地図の種別と右下出典が一致していることを確認する。

**Acceptance Scenarios**:

1. **Given** 地図画面を初めて開く, **When** 初期背景地図が表示される, **Then** 右下出典はその背景地図に対応した文言になっている。
2. **Given** 背景地図切り替え後の状態, **When** 同一セッション内で再描画される, **Then** 背景地図と右下出典の組み合わせは常に一致する。

---

### Edge Cases

- 切り替えUIで現在と同じ背景地図を再選択した場合でも、表示が不整合にならないこと。
- 背景地図の読み込みに失敗した場合、利用者に現在状態を誤認させる出典表示にならないこと。
- 切り替え操作を短時間に連続実行した場合でも、最終選択と出典表示が一致すること。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: システムは画面左下に背景地図切り替え操作を提供しなければならない。
- **FR-002**: システムは背景地図として OpenStreetMap、地理院地図、航空写真の3種類を選択可能にしなければならない。
- **FR-003**: システムは背景地図の選択直後に表示を選択種別へ切り替えなければならない。
- **FR-004**: システムは画面右下に表示する出典を、現在表示中の背景地図種別に応じて切り替えなければならない。
- **FR-005**: システムは初期表示時にも、背景地図と右下出典の対応関係を一致させなければならない。
- **FR-006**: システムは切り替え操作後に、背景地図と出典の不一致状態を残してはならない。

### Key Entities *(include if feature involves data)*

- **背景地図種別**: 利用者が選択できる背景地図の定義。値は OpenStreetMap、地理院地図、航空写真。
- **出典表示ルール**: 背景地図種別と右下出典文言の対応関係を表す定義。
- **表示状態**: 現在画面に描画されている背景地図種別と出典文言の組み合わせ。

## Quality Requirements *(mandatory)*

- **QR-001**: 背景地図切り替え時に、利用者が不整合を視認する状態を発生させないこと。
- **QR-002**: 各背景地図種別に対して、対応する出典表示ルールの検証シナリオを定義すること。
- **QR-003**: 切り替え機能の仕様、テスト観点、運用上の注意を日本語で記述すること。
- **QR-004**: 異常時や連続操作時の挙動を明示し、回帰確認可能な受け入れ条件を維持すること。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 利用者は3種類の背景地図を左下操作から100%選択できる。
- **SC-002**: 背景地図切り替え操作の受け入れシナリオで、右下出典の対応一致率が100%である。
- **SC-003**: 初期表示および連続切り替えの検証シナリオで、背景地図と出典の不一致件数が0件である。
- **SC-004**: 機能リリース後、背景地図と出典の不一致に関する問い合わせが0件である。

## Assumptions

- 3種類の背景地図は既存の地図表示基盤上で利用可能である。
- 右下出典表示領域は既存UIとして利用できる。
- 表示文言は運用ルールに沿って事前合意済みである。
- 本機能は単一画面の背景地図表示を対象とし、他画面の出典表示仕様は本スコープ外とする。
