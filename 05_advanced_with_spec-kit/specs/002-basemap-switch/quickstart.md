# クイックスタート: 背景地図切り替えと出典連動表示

## 前提
- Node.js 18+
- npm

## 1. 依存関係の導入
```bash
npm install
```

## 2. 開発サーバー起動
```bash
npm run dev
```

## 3. 受け入れ確認手順
1. 地図画面を開く。
2. 画面左下の背景地図切り替えUIを確認する。
3. `OpenStreetMap` を選択し、背景と右下出典が一致することを確認する。
4. `地理院地図` を選択し、背景と右下出典が一致することを確認する。
5. `航空写真` を選択し、背景と右下出典が一致することを確認する。
6. 初期表示時の背景と出典が一致することを確認する。
7. 連続で切り替えても最終選択と出典が一致することを確認する。
