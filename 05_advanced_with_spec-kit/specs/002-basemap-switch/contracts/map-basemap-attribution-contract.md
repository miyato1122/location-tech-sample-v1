# 契約定義: 背景地図切り替えと出典表示

## 目的
背景地図切り替え操作と右下出典表示の整合ルールを定義し、UI実装・テスト・レビューで共通利用する。

## 背景地図種別
- `osm`: OpenStreetMap
- `gsi_std`: 国土地理院 地理院地図
- `gsi_ortho`: 国土地理院 航空写真

## UI契約
1. 背景地図切り替え操作は画面左下に配置する。
2. 切り替え操作後、表示背景地図は選択種別に更新される。
3. 右下出典は選択中背景地図に対応する文言へ更新される。
4. 初期表示時から背景地図と出典は一致している。

## 出典表示契約
- `osm` 表示時: `出典: OpenStreetMap contributors`
- `gsi_std` 表示時: `出典: 国土地理院 地理院地図`
- `gsi_ortho` 表示時: `出典: 国土地理院 航空写真`

## 不整合禁止条件
- 出典だけ先に切り替わる状態を許容しない。
- 背景地図だけ先に切り替わる状態を許容しない。
- 失敗時に選択中表示と出典が異なる状態を残さない。

## 受け入れ検証
- 各背景地図へ切り替えた時、右下出典が対応文言へ更新されること。
- 連続切り替え時、最終選択と出典が一致すること。
- 初期表示時に背景地図と出典が一致すること。
