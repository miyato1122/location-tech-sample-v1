# クイックスタート: 背景地図切り替え機能の動作確認

**フィーチャー**: 001-basemap-switcher
**作成日**: 2026-04-22

## 開発サーバーの起動

```bash
cd 06_advanced_with_spec-kit-cc
npm install
npm run dev
```

ブラウザで `http://localhost:5173`（または表示されたURL）を開く。

## 動作確認手順

### 確認 1: コントロールの配置（FR-001, SC-003）

1. 地図が表示されたら画面左下を確認する
2. 「OpenStreetMap」「地理院地図」「航空写真」の3項目を持つ
   ラジオボタングループが表示されていることを確認する
3. 既存のコントロール（左上のハザードマップ、右上の避難場所）と
   重なっていないことを確認する

### 確認 2: デフォルト表示（FR-006, SC-004）

1. ページ読み込み直後、「OpenStreetMap」のラジオボタンが選択状態になっていることを確認する
2. 背景地図が OpenStreetMap で表示されていることを確認する

### 確認 3: 地理院地図への切り替え（FR-003, SC-001）

1. 「地理院地図」のラジオボタンをクリックする
2. 背景地図が国土地理院の標準地図（薄い色調の日本語地図）に変わることを確認する
3. 地図右下の出典に「国土地理院」が表示されることを確認する（FR-008, SC-005）

### 確認 4: 航空写真への切り替え

1. 「航空写真」のラジオボタンをクリックする
2. 背景地図が衛星写真に変わることを確認する
3. 地図右下の出典に「国土地理院」が表示されることを確認する

### 確認 5: OpenStreetMap への復帰

1. 「OpenStreetMap」のラジオボタンをクリックする
2. 背景地図が OpenStreetMap に戻ることを確認する
3. 地図右下の出典に「© OpenStreetMap contributors」が表示されることを確認する

### 確認 6: オーバーレイとの共存（FR-005, SC-002）

1. 左上のコントロールでハザードマップ（洪水浸水想定区域など）を表示する
2. 背景地図を切り替える
3. ハザードマップのオーバーレイが消えずに維持されていることを確認する

## ビルド確認

```bash
npm run build
```

エラーなしでビルドが完了することを確認する。
