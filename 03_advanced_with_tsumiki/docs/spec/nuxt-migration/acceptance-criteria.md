## REQ-001 / REQ-002: Nuxt 3プロジェクト初期化・CSRモード 🔵

**信頼性**: 🔵 *ユーザーヒアリングより*

### Given（前提条件）
- Node.js 18以上がインストールされている

### When（実行条件）
- `nuxt.config.ts` に `ssr: false` を設定してビルド・起動する

### Then（期待結果）
- `ssr: false` が設定されている
- `npm run dev` でローカルサーバーが起動する
- MapLibre GL JSのインポートがサーバーサイドで実行されない

### テストケース

#### 正常系

- [ ] **TC-001-01**: CSRモードの確認 🔵
  - **入力**: `nuxt.config.ts` の `ssr: false`
  - **期待結果**: HTMLがクライアントでレンダリングされる（初期レスポンスにマップDOMなし）
  - **信頼性**: 🔵

- [ ] **TC-001-02**: 開発サーバー起動 🔵
  - **入力**: `npm run dev`
  - **期待結果**: エラーなくlocalhostで起動する
  - **信頼性**: 🔵

#### 異常系

- [ ] **TC-001-E01**: SSRコンテキストでのMapLibreインポート防止 🔵
  - **入力**: `onMounted` の外でMapLibreをインポートした場合
  - **期待結果**: Nuxt 3がコンパイルエラーまたは実行時エラーで検出可能
  - **信頼性**: 🔵
