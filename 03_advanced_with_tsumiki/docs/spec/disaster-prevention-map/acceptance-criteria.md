# 防災マップ 受け入れ基準（逆生成）

## 機能別受け入れ基準

---

### AC-001: 地図表示

- [x] アプリ起動時、日本中央部（経度138°、緯度37°）を中心にズームレベル5で地図が表示される
- [x] ズームレベルは5〜18の範囲内でのみ操作できる
- [x] 地図の移動は日本の地理的範囲（経度122〜154°、緯度20〜50°）内に制限される
- [x] 背景地図にOpenStreetMapが表示され、著作権表示が地図上に表示される

---

### AC-002: ハザードマップ表示

- [x] 左上のコントロールに6種類のハザードマップがリスト表示される
- [x] 各ハザードマップの表示/非表示を個別に切り替えられる
- [x] 表示時の不透明度は70%（視認性を保ちながら背景地図も見える）
- [x] ハザードマップ表示時に国土地理院ハザードマップポータルサイトの著作権表示が表示される
- [ ] 複数ハザードを同時に表示した場合の重なり順が適切に制御される

---

### AC-003: 指定緊急避難場所表示

- [x] 右上のコントロールに8種類の災害種別がリスト表示される
- [x] 選択した災害種別に対応する避難場所のみが地図上に表示される
- [x] 避難場所は紫色（#6666cc）のサークルで表示される
- [x] サークルのサイズはズームレベルに応じて変化する（zoom5: 2px、zoom14: 6px）
- [x] 国土地理院指定緊急避難場所データの著作権表示が表示される

---

### AC-004: 避難場所のポップアップ

- [x] 避難場所のサークルをクリック/タップすると詳細情報が表示される
- [x] ポップアップには以下の情報が表示される:
  - [x] 施設名称（太字、大きいフォント）
  - [x] 住所
  - [x] 備考（ある場合のみ）
  - [x] 8種類の災害種別の対応状況（対応: 通常表示、未対応: グレーアウト）
- [x] 避難場所上にマウスカーソルを重ねると、カーソルがポインター形状に変わる
- [x] ポップアップの最大幅は400pxに制限される

---

### AC-005: 位置情報と最近傍ルート

- [x] 位置情報取得ボタンが右下に表示される
- [x] ボタンを押して権限を許可すると、現在地がマップ上に表示される
- [x] ズームレベルが7以上かつ現在地が取得されている場合、最寄り避難場所への青線（#33aaff、幅4px）が表示される
- [x] ズームレベルが7未満の場合、ルート線は非表示になる
- [x] 位置情報追跡を停止した場合、ルート線は消える
- [x] 最近傍検索は現在表示中の災害種別に対応した避難場所のみを対象とする
- [ ] 避難場所データが読み込まれていない場合（タイル未取得状態）のエラーハンドリング

---

### AC-006: 3D地形・陰影図

- [x] マップ上に3D地形コントロールが表示される
- [x] 3D地形コントロールを有効化すると地形が立体的に表示される
- [x] 陰影図がデフォルトで表示され、地形の立体感を視覚的に表現する

---

### AC-007: PWA機能

- [x] スマートフォンのブラウザでアクセスした際に「ホーム画面に追加」が可能
- [x] ホーム画面に追加された際のアイコンが表示される（192, 256, 384, 512px）
- [x] アプリ名「防災マップ」がホーム画面上に表示される
- [x] スタンドアロンモード（ブラウザUIなし）で起動できる
- [ ] Service Worker によるオフラインキャッシュの具体的な動作確認（現状sw.jsは最小実装）

---
