### US-001: 周辺のハザードリスク確認

**である** 日本国内の居住者・就労者 **として**  
**私は** 自宅・職場周辺のハザードマップを地図上で確認 **をしたい**  
**そうすることで** 洪水・津波・土砂災害などのリスクを事前に把握できる

**実装根拠**:
- `main.js:35-100` — 6種のハザードマップソース定義
- `main.js:430-440` — `OpacityControl`（左上）によるハザードレイヤー制御

### US-003: 避難場所の詳細情報確認

**である** 避難行動を計画している市民 **として**  
**私は** 地図上の避難場所アイコンをタップ/クリックして施設の詳細情報を確認 **をしたい**  
**そうすることで** 名称・住所・対応災害種別を確認し、適切な避難先を選択できる

- ポップアップ表示項目: 名称、住所、備考、8種の災害種別対応状況
