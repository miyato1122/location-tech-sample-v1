## REQ-001〜REQ-003: 常時表示・初期状態 🔵

**信頼性**: 🔵 *`_buildUI()`・`map.addControl` 実装より*

### Given（前提条件）
- 防災マップが正常に起動し、`map.on('load')` が完了している

### When（実行条件）
- ユーザーが地図を開く（何も操作しない）

### Then（期待結果）
- 地図の左下に「OSM」「地理院地図」「航空写真」「白地図」のラジオボタンが縦に並んで表示される
- 「OSM」のラジオボタンが選択済み（checked）になっている
- 背景地図として OpenStreetMap タイルが表示されている

### テストケース

- [x] **TC-001-01**: マップロード後に背景地図切り替えパネルが `bottom-left` に表示される 🔵
- [x] **TC-001-02**: 初期状態で「OSM」ラジオボタンが `checked` 状態である 🔵
- [x] **TC-001-03**: パネルに「OSM」「地理院地図」「航空写真」「白地図」の4項目が表示される 🔵

## REQ-004: ラジオボタンによる即時切り替え 🔵

**信頼性**: 🔵 *`_switchBasemap()`・`setLayoutProperty` 実装より*

### Given（前提条件）
- マップが表示状態、初期背景地図は OSM

### When（実行条件）
- ユーザーが「地理院地図」ラジオボタンをクリックする

### Then（期待結果）
- 背景地図が国土地理院標準地図（`cyberjapandata.gsi.go.jp/xyz/std/`）に切り替わる
- `gsi-std-layer` の `visibility` が `visible` になる
- `osm-layer` の `visibility` が `none` になる

### テストケース

- [x] **TC-004-01**: OSM → 地理院地図 に切り替えできる 🔵
- [x] **TC-004-02**: OSM → 航空写真 に切り替えできる 🔵
- [x] **TC-004-03**: 地理院地図 → 航空写真 に切り替えできる 🔵
- [x] **TC-004-04**: 航空写真 → OSM に切り替えできる（一巡） 🔵
- [x] **TC-004-05**: OSM → 白地図 に切り替えできる 🔵
- [x] **TC-004-06**: 白地図 → OSM に切り替えできる（一巡） 🔵

## REQ-101: 同一背景地図の再選択はスキップ 🔵

**信頼性**: 🔵 *`if (id === this._currentBasemap) return;` より*

### Given（前提条件）
- 現在「地理院地図」が選択されている

### When（実行条件）
- ユーザーが再度「地理院地図」ラジオボタンをクリックする

### Then（期待結果）
- `change` イベントは発火するが `_switchBasemap` 内で即座にリターンし、地図操作は行われない
- 表示状態に変化なし

### テストケース

- [x] **TC-101-01**: 同じ背景地図を再選択しても地図が乱れない 🔵

## REQ-005 / NFR-005: 他レイヤーへの影響なし 🔵

**信頼性**: 🔵 *`_switchBasemap` の操作対象が `this._basemaps` 配列内のみであることを確認*

### Given（前提条件）
- ハザードマップ（洪水浸水想定区域）と避難場所レイヤーが表示されている

### When（実行条件）
- 背景地図を OSM → 航空写真 に切り替える

### Then（期待結果）
- `hazard_*-layer` の `visibility` は変化しない
- `skhb-*-layer` の `visibility` は変化しない
- ハザードマップ・避難場所のオーバーレイが引き続き表示される

### テストケース

- [x] **TC-005-01**: 背景地図切り替え後もハザードマップオーバーレイが維持される 🔵
- [x] **TC-005-02**: 背景地図切り替え後も避難場所レイヤーが維持される 🔵
