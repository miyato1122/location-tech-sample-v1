## エピック1: 背景地図の選択・切り替え

### ストーリー 1.1: 背景地図の常時選択 🔵

**信頼性**: 🔵 *`_buildUI()` のラジオボタン実装・`bottom-left` 配置より*

**私は** 防災マップを利用する一般ユーザー **として**
**地図左下に常時表示されたラジオボタンで背景地図を選択したい**
**そうすることで** ボタンを探す手間なく、いつでも好みの背景地図に切り替えられる

**関連要件**: REQ-001, REQ-002, REQ-003, REQ-004

**詳細シナリオ**:
1. マップが表示された時点で、左下に「OSM」「地理院地図」「航空写真」のラジオボタンが表示される
2. 初期状態では「OSM」が選択済みになっている
3. 「地理院地図」ラジオボタンをクリックする
4. 即座に背景地図が地理院標準地図に切り替わる

**実装根拠**:
- `map.addControl(new BasemapSwitcherControl(), 'bottom-left')` — 常時表示・配置
- `radio.checked = id === this._currentBasemap` — OSM 初期選択
- `radio.addEventListener('change', ...)` — 即時切り替え

**優先度**: Must Have

### ストーリー 1.2: 航空写真での地形確認 🔵

**信頼性**: 🔵 *`gsi_photo` ソース定義・`seamlessphoto` タイルURLより*

**私は** 避難経路を検討しているユーザー **として**
**航空写真に切り替えて建物・地形の実際の様子を確認したい**
**そうすることで** 標準地図だけではわからない地形の詳細や建物の形状を把握できる

**関連要件**: REQ-002, REQ-004

**詳細シナリオ**:
1. 「航空写真」ラジオボタンをクリックする
2. 背景地図が国土地理院のシームレス航空写真タイルに切り替わる
3. 地図右下の出典表示が「国土地理院」に更新される

**実装根拠**:
- `{ id: 'gsi_photo', tiles: ['https://cyberjapandata.gsi.go.jp/xyz/seamlessphoto/...'] }` — ソース定義
- `attribution: '..国土地理院..'` — 出典自動更新

**優先度**: Must Have

### ストーリー 1.3: ハザードマップを維持しながら背景を変える 🔵

**信頼性**: 🔵 *`_switchBasemap` が `this._basemaps` 内レイヤーのみ操作することを実装で確認*

**私は** ハザードマップを表示中のユーザー **として**
**ハザードマップのオーバーレイを消さずに背景地図だけを切り替えたい**
**そうすることで** 洪水浸水区域を航空写真や地理院地図の上に重ねて確認できる

**関連要件**: REQ-005, NFR-005

**詳細シナリオ**:
1. ハザードマップ（例: 洪水浸水想定区域）を表示した状態で「航空写真」を選択する
2. 背景地図が切り替わる
3. 洪水浸水想定区域のオーバーレイは変わらず表示され続ける

**実装根拠**:
- `_switchBasemap` は `this._basemaps`（背景3レイヤー）のみ `visibility` を操作
- ハザードマップレイヤー（`hazard_*-layer`）は操作対象外

**優先度**: Must Have
