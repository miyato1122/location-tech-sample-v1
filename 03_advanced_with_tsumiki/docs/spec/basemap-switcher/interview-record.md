# 背景地図切り替え機能 ヒアリング記録

**作成日**: 2026-04-21
**ヒアリング実施**: step4 既存情報ベースの差分ヒアリング

## ヒアリング目的

既存の設計文書・実装を確認し、背景地図切り替え機能の仕様について不明点を明確化するためのヒアリングを実施しました。

---

## 質問と回答

### Q1: 切り替えUIの形式

**質問日時**: 2026-04-21
**カテゴリ**: 未定義部分詳細化
**背景**: 要件では「画面左下に表示する」とのことだが、UIの具体的な形式（常時表示パネル vs アイコンボタン）が未定義だったため確認が必要。

**質問**: 画面左下に表示する切り替えUIの形式はどれがよいですか？
**回答**: アイコンボタン（クリックで展開するドロップダウン）

**信頼性への影響**:
- REQ-001（UIアイコンボタン）の信頼性レベルが 🔴 → 🔵 に向上

---

### Q2: 出典表示（attribution）の扱い

**質問日時**: 2026-04-21
**カテゴリ**: 未定義部分詳細化
**背景**: 地図タイルの切り替えに伴い、出典表示（OpenStreetMap / 国土地理院）も切り替える必要があるか確認が必要。

**質問**: 背景地図の出典表示（attribution）はどうしますか？
**回答**: 切り替え時に表示を切り替える（MapLibre の attributionControl で自動更新）

**信頼性への影響**:
- REQ-004（出典表示の切り替え）の信頼性レベルが 🔴 → 🔵 に向上

---

## ヒアリング結果サマリー

### 確認できた事項
- UIはアイコンボタン（左下固定）でクリック展開方式を採用
- 出典表示は MapLibre の attributionControl に委ね、ソース切り替えで自動更新

### 追加/変更要件
- なし（要件はユーザーの説明通りに定義済み）

### 残課題
- アイコンのデザイン・テキストラベルの具体的な内容（設計フェーズで決定）
- ドロップダウンメニューの展開方向（上向き推奨だが設計フェーズで確認）

### 信頼性レベル分布

**ヒアリング前**:
- 🔵 青信号: 1件
- 🟡 黄信号: 2件
- 🔴 赤信号: 2件

**ヒアリング後**:
- 🔵 青信号: 5件 (+4)
- 🟡 黄信号: 3件 (+1)
- 🔴 赤信号: 0件 (-2)
