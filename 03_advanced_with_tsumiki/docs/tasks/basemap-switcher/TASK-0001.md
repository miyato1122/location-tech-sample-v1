## タスク概要

`main.js` の MapLibre GL JS 初期スタイル定義に、国土地理院地図・航空写真の2つのラスタータイルソースと対応レイヤーを追加する。既存の OSM レイヤーにも `visibility` の明示指定を追加する。これにより、TASK-0002 で実装するコントロールクラスが `setLayoutProperty` で visibility を切り替えられる状態にする。

## 依存タスク

- **前提タスク**: なし
- **後続タスク**: [TASK-0002: BasemapSwitcherControl クラス実装](TASK-0002.md)

## 完了条件

- [ ] `main.js` の `style.sources` に `gsi_std`（地理院地図）ソースが追加されている
- [ ] `main.js` の `style.sources` に `gsi_photo`（地理院航空写真）ソースが追加されている
- [ ] `main.js` の `style.layers` の最初（ハザードマップレイヤーより前）に `gsi-std-layer`（`visibility: 'none'`）が追加されている
- [ ] `main.js` の `style.layers` の最初に `gsi-photo-layer`（`visibility: 'none'`）が追加されている
- [ ] 既存の `osm-layer` に `layout: { visibility: 'visible' }` が明示追加されている
- [ ] `npm run dev` でアプリが正常に起動し、地図が表示されること（既存機能に影響なし）

## 主要実装項目

### 1. 地理院地図ソース追加（`gsi_std`）🔵

**信頼性**: 🔵 *architecture.md「追加するソース」・note.md「追加する地図タイル情報」より*

**実装ファイル**: `main.js`

`style.sources` オブジェクト内の `osm` ソース定義の直後に追加する。

```javascript
// style.sources に追加
gsi_std: {
    type: 'raster',
    tiles: ['https://cyberjapandata.gsi.go.jp/xyz/std/{z}/{x}/{y}.png'],
    maxzoom: 18,
    tileSize: 256,
    attribution:
        '<a href="https://maps.gsi.go.jp/development/ichiran.html" target="_blank">国土地理院</a>',
},
gsi_photo: {
    type: 'raster',
    tiles: ['https://cyberjapandata.gsi.go.jp/xyz/seamlessphoto/{z}/{x}/{y}.jpg'],
    maxzoom: 18,
    tileSize: 256,
    attribution:
        '<a href="https://maps.gsi.go.jp/development/ichiran.html" target="_blank">国土地理院</a>',
},
```

### 2. 背景地図レイヤー追加と既存レイヤー修正 🔵

**信頼性**: 🔵 *architecture.md「追加するレイヤー」・ユーザヒアリングより*

**実装ファイル**: `main.js`

`style.layers` の先頭部分（`osm-layer` の定義箇所）を以下のように変更する。

```javascript
// 変更前
{
    id: 'osm-layer',
    source: 'osm',
    type: 'raster',
},

// 変更後
{
    id: 'osm-layer',
    source: 'osm',
    type: 'raster',
    layout: { visibility: 'visible' },
},
{
    id: 'gsi-std-layer',
    source: 'gsi_std',
    type: 'raster',
    layout: { visibility: 'none' },
},
{
    id: 'gsi-photo-layer',
    source: 'gsi_photo',
    type: 'raster',
    layout: { visibility: 'none' },
},
```

## 注意事項

- `gsi_photo` のタイル形式は JPEG（`.jpg`）。OSM の PNG とは異なる
- `gsi-std-layer` と `gsi-photo-layer` は `osm-layer` の直後に追加し、ハザードマップレイヤーより前に配置すること（レイヤー順序が重要）
- 国土地理院タイルは認証不要（パブリック利用可能）
