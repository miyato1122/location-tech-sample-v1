## タスク概要

`style.css` に `BasemapSwitcherControl` の CSS を追記する。MapLibre GL JS の既存コントロール（GeolocateControl、TerrainControl 等）が持つ `.maplibregl-ctrl-group` スタイルと視覚的に調和するよう、ボタンサイズ・フォント・背景色・ホバー状態を定義する。モバイル（タッチ操作）でも扱いやすいサイズを確保する。

## 主要実装項目

### 1. コントロールコンテナスタイル 🟡

**信頼性**: 🟡 *REQ-402（MapLibre コントロールとの調和）・REQ-403から妥当な推測*

**実装ファイル**: `style.css`

```css
/* 背景地図切り替えコントロール */
.basemap-switcher {
    position: relative;
}

/* トグルボタン（アイコン） */
.basemap-switcher-toggle {
    display: flex;
    align-items: center;
    justify-content: center;
    width: 29px;
    height: 29px;
    background: #fff;
    border: none;
    cursor: pointer;
    font-size: 16px;
    padding: 0;
}

.basemap-switcher-toggle:hover {
    background-color: #f2f2f2;
}

/* ドロップダウンメニュー（ボタン上方向に展開） */
.basemap-switcher-menu {
    position: absolute;
    bottom: 100%;
    left: 0;
    background: #fff;
    box-shadow: 0 1px 4px rgba(0, 0, 0, 0.3);
    border-radius: 4px;
    margin-bottom: 4px;
    min-width: 90px;
    overflow: hidden;
}

/* メニュー内の各ボタン */
.basemap-switcher-item {
    display: block;
    width: 100%;
    padding: 8px 12px;
    background: none;
    border: none;
    text-align: left;
    font-size: 12px;
    cursor: pointer;
    white-space: nowrap;
    min-height: 44px;
    line-height: 28px;
}

.basemap-switcher-item:hover {
    background-color: #f2f2f2;
}

/* 選択中の地図をハイライト */
.basemap-switcher-item.active {
    font-weight: bold;
    background-color: #e8f0fe;
    color: #1a73e8;
}
```

## 注意事項

- `style.css` は現在空ファイル。新規スタイルを追記するだけでよい
- MapLibre GL JS の `.maplibregl-ctrl-group` クラスが自動適用されるため、基本的な枠線・影・角丸は既存スタイルに任せられる
- メニューは `bottom: 100%` で上方向に展開させること（`bottom-left` 配置のため、下方向展開すると画面外に出る）
