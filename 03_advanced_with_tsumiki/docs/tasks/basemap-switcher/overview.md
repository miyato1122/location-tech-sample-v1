## 実装上の注意点

- `BasemapSwitcherControl` クラスは `map.on('load', ...)` の**前**（グローバルスコープ）に定義する
- コントロール登録（`map.addControl`）は `map.on('load')` コールバック**内**で行う
- 国土地理院タイルの `.jpg` 拡張子を OSM の `.png` と混同しないよう注意
