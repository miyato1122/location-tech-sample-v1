## タスク概要

`map.on('load')` コールバック内で `BasemapSwitcherControl` を地図の `bottom-left` に登録する。その後、MapLibre GL JS の `AttributionControl` の挙動を実機で確認し、必要に応じて背景地図切り替え時の attribution 手動更新処理を追加する。

- **前提タスク**: [TASK-0003: コントロールスタイル実装](TASK-0003.md)
- **後続タスク**: なし

## 完了条件

- [ ] `map.on('load')` 内に `map.addControl(new BasemapSwitcherControl(), 'bottom-left')` が追加されている
- [ ] 地図左下にコントロールが表示されている
- [ ] OSM → 地理院地図 → 地理院航空写真 → OSM の順に切り替えができる
- [ ] 切り替え後に画面右下の attribution が切り替え後の地図に合わせて更新される（または適切に対応されている）
- [ ] ハザードマップ・避難場所レイヤーが切り替え後も正常に動作する
- [ ] ブラウザコンソールにエラーが出ない

## 主要実装項目

### 1. コントロールの登録 🔵

**信頼性**: 🔵 *REQ-001・architecture.md「コントロール配置」より*

**実装ファイル**: `main.js`

`map.on('load', () => { ... })` の内部、他のコントロール登録（OpacityControl 等）の後に追加する。

```javascript
// map.on('load', callback) 内部
map.addControl(new BasemapSwitcherControl(), 'bottom-left');
```

### 2. Attribution 挙動の確認と対応 🟡

**信頼性**: 🟡 *REQ-004・dataflow.md「Attribution 更新フロー」より（実機確認が必要な検証ポイント）*

**実装ファイル**: `main.js`（必要な場合のみ `BasemapSwitcherControl._switchBasemap` に追記）

MapLibre GL JS の `AttributionControl` が visibility に基づいて attribution を自動更新するかを確認する。

**確認手順**:
1. ブラウザで地図を開き、画面右下の attribution 表示を確認
2. 背景地図を OSM → 地理院地図に切り替え、attribution が「国土地理院」に変わるか確認
3. attribution が自動更新されない場合は、`_switchBasemap` メソッド内に以下を追加する

```javascript
// attribution が自動更新されない場合の対応（_switchBasemap 内に追記）
// ※ 自動更新される場合は不要
_updateAttribution(id) {
    const attributions = {
        osm: '&copy; <a href="http://www.openstreetmap.org/copyright">OpenStreetMap</a> contributors',
        gsi_std: '<a href="https://maps.gsi.go.jp/development/ichiran.html" target="_blank">国土地理院</a>',
        gsi_photo: '<a href="https://maps.gsi.go.jp/development/ichiran.html" target="_blank">国土地理院</a>',
    };
    // MapLibre GL JS の内部 attribution 更新APIを使用
    // ※ 具体的な実装は MapLibre GL JS のバージョンに依存するため実装時に確認
}
```
