## 実装詳細

### クリックイベント処理

1. `map.on('click')` で地図クリックを検出
2. `queryRenderedFeatures(e.point, { layers: ['skhb-1-layer', ..., 'skhb-8-layer'] })` で対象フィーチャーを取得
3. フィーチャーが存在しない場合は処理終了（`return`）
4. `features[0]` の座標にポップアップを配置
5. HTML文字列でポップアップコンテンツを生成

### ポップアップ表示内容

```
[施設名称（太字、1.2rem）]
[住所]
[備考（存在する場合）]
[洪水] [崖崩れ/土石流/地滑り] [高潮] [地震]
[津波] [大規模な火事] [内水氾濫] [火山現象]
※対応していない災害種別はグレー表示（color:#ccc）
```

### 注意点

- `feature.properties.remarks ?? ''` により remarks が null の場合も安全に処理
- 複数フィーチャーが重なる場合は `features[0]` のみ表示
- HTML文字列直接生成（XSSリスクは低いがベクトルタイル属性値次第）
