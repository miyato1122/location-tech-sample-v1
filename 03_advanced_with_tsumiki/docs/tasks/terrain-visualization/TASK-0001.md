## 実装詳細

```javascript
// 地形データ生成（地理院標高タイル）
const gsiTerrainSource = useGsiTerrainSource(maplibregl.addProtocol);

// raster-dem ソース追加
map.addSource('terrain', gsiTerrainSource);

// 陰影図レイヤー追加（hazard_jisuberi-layer の手前に挿入）
map.addLayer(
    {
        id: 'hillshade',
        source: 'terrain',
        type: 'hillshade',
        paint: {
            'hillshade-illumination-anchor': 'map', // 地図基準の光源方向
            'hillshade-exaggeration': 0.2,          // 陰影の強さ（控えめ）
        },
    },
    'hazard_jisuberi-layer', // このレイヤーの手前に配置
);
```

- `useGsiTerrainSource` はカスタムプロトコルを `maplibregl.addProtocol` で登録し、国土地理院の標高タイルを raster-dem 形式で読み込む
- `hillshade-illumination-anchor: 'map'` により、地図の回転に合わせて光源方向が固定される
