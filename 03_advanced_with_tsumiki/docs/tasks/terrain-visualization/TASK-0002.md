## 実装詳細

```javascript
map.addControl(
    new maplibregl.TerrainControl({
        source: 'terrain',  // raster-dem ソースのID
        exaggeration: 1,    // 標高を実際の1倍（誇張なし）
    }),
);
```

- 地図画面上にトグルボタンが表示され、ON/OFFで3D地形表示を切り替えられる
- `terrain` ソースは TASK-0001 で追加済みのものを参照
- `exaggeration: 1` は実際の標高に忠実な3D表現（`hillshade` の `0.2` とは別設定）
