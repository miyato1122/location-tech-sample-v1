## 実装詳細

```javascript
let userLocation = null; // [lng, lat] または null

const geolocationControl = new maplibregl.GeolocateControl({
    trackUserLocation: true,
});
map.addControl(geolocationControl, 'bottom-right');

geolocationControl.on('geolocate', (e) => {
    userLocation = [e.coords.longitude, e.coords.latitude];
});
```

- `trackUserLocation: true` により、ユーザーが移動するたびに位置情報が更新される
- `userLocation` はモジュールスコープ変数（グローバル変数相当）でルート計算に使用される
- ブラウザの権限ダイアログはMapLibre GL JSが内部的に処理
