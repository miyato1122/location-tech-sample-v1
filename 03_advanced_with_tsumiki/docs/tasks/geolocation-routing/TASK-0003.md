### render イベントによるリアルタイム更新（`main.js:542-577`）

```javascript
map.on('render', () => {
    // 追跡停止時は位置情報をクリア
    if (geolocationControl._watchState === 'OFF') userLocation = null;

    // ズーム < 7 または位置情報なし → ルートをクリア
    if (map.getZoom() < 7 || userLocation === null) {
        map.getSource('route').setData({ type: 'FeatureCollection', features: [] });
        return;
    }

    // 最近傍施設を取得してルートを描画
    const nearestFeature = getNearestFeature(userLocation[0], userLocation[1]);
    // ⚠️ nearestFeature が null の場合 TypeError が発生する（バグリスク）
    const routeFeature = {
        type: 'Feature',
        geometry: {
            type: 'LineString',
            coordinates: [userLocation, nearestFeature._geometry.coordinates],
        },
    };
    map.getSource('route').setData({ type: 'FeatureCollection', features: [routeFeature] });
});
```

### 表示条件

| 条件 | ルート表示 |
|------|----------|

| 位置情報取得中 + ズーム < 7 | 非表示 |
| GeolocateControl が OFF | 非表示 |
| 位置情報権限未許可 | 非表示 |
