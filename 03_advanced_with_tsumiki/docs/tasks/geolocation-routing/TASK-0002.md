## 実装詳細

### getCurrentSkhbLayerFilter()（`main.js:371-382`）

現在 visible 状態の skhb レイヤーの filter 条件を取得する。

```javascript
const getCurrentSkhbLayerFilter = () => {
    const style = map.getStyle();
    const skhbLayers = style.layers.filter((layer) =>
        layer.id.startsWith('skhb'),
    );
    const visibleSkhbLayers = skhbLayers.filter(
        (layer) => layer.layout.visibility === 'visible',
    );
    return visibleSkhbLayers[0].filter; // 例: ['get', 'disaster4']
};
```

### getNearestFeature()（`main.js:387-413`）

指定座標から最寄りの避難場所フィーチャーを返す。

```javascript
const getNearestFeature = (longitude, latitude) => {
    const currentSkhbLayerFilter = getCurrentSkhbLayerFilter();
    const features = map.querySourceFeatures('skhb', {
        sourceLayer: 'skhb',
        filter: currentSkhbLayerFilter,
    });

    const nearestFeature = features.reduce((minDistFeature, feature) => {
        const dist = distance(
            [longitude, latitude],
            feature.geometry.coordinates,
        );
        if (minDistFeature === null || minDistFeature.properties.dist > dist)
            return { ...feature, properties: { ...feature.properties, dist } };
        return minDistFeature;
    }, null);

    return nearestFeature; // フィーチャーがない場合は null
};
```

### 既知のバグリスク

`features` が空配列の場合、`reduce()` は初期値 `null` を返す。
呼び出し元（`main.js:568`）で `nearestFeature._geometry.coordinates` を参照しているため、null の場合は TypeError が発生する。

**修正案**:
```javascript
// main.js:556 付近に追加が必要
const nearestFeature = getNearestFeature(userLocation[0], userLocation[1]);
if (!nearestFeature) return; // ← null チェック追加
```
