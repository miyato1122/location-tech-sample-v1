## 実装詳細

### 1. 既存型定義の移行 🔵

**信頼性**: 🔵 *既存 docs/design/disaster-prevention-map/interfaces.ts より*

**実装ファイル**: `types/index.ts`

以下の型を `docs/design/nuxt-migration/interfaces.ts` の内容をもとに `types/index.ts` に実装する：

- `SkhbProperties` — 避難場所フィーチャーのプロパティ
- `SkhbFeatureWithDistance` — 距離計算後フィーチャー
- `HazardLayerId` / `SkhbLayerId` — レイヤーID ユニオン型
- `UserLocation` — 現在地座標（null含む）
- `GeolocateEventData` — GeolocateControlイベントデータ
- `VectorTileMetadata` — ベクトルタイルメタデータ

### 2. 新規型・定数の追加 🔵

**信頼性**: 🔵 *REQ-010, REQ-030, REQ-040, REQ-060 + アーキテクチャ設計より*

追加する型・定数：
- `MAP_INIT_CONFIG` — マップ初期設定定数
- `DISASTER_LABELS` — 災害種別ラベルマッピング
- `SKHB_LAYER_IDS` — 全避難場所レイヤーID配列
- `HAZARD_LAYER_DEFINITIONS` — ハザードマップ定義一覧
- `UseMapReturn` — useMap戻り値型
- `UseShelterLayersReturn` — useShelterLayers戻り値型
- `UseGeolocationReturn` — useGeolocation戻り値型
- `NearestFeatureResult` — getNearestFeature戻り値型
- `ShelterPopupProps` — ShelterPopup.vue props型

### 3. maplibre-gl-opacity 型補完 🟡

**信頼性**: 🟡 *パッケージ調査から妥当な推測*

`maplibre-gl-opacity` に型定義が存在しない場合、`types/maplibre-gl-opacity.d.ts` を作成：

```typescript
declare module 'maplibre-gl-opacity' {
  import { Map } from 'maplibre-gl'
  interface OpacityControlOptions {
    baseLayers?: Record<string, string>
    overLayers?: Record<string, string>
    opacityControl?: boolean
  }
  class OpacityControl {
    constructor(options: OpacityControlOptions)
    onAdd(map: Map): HTMLElement
    onRemove(): void
  }
  export { OpacityControl }
}
```
