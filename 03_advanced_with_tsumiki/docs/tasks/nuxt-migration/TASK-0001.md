
### 2. nuxt.config.ts 設定 🔵

**信頼性**: 🔵 *REQ-002 + ユーザーヒアリングより*

**実装ファイル**: `nuxt.config.ts`

```typescript
export default defineNuxtConfig({
  ssr: false,  // MapLibre GL JS のSSR問題を回避（REQ-002）
  modules: [
    '@vite-pwa/nuxt',
  ],
  typescript: {
    strict: true,
  },
})
```

### 3. 依存パッケージのインストール 🔵

**信頼性**: 🔵 *既存 package.json + ユーザーヒアリングより*

```bash
# 本番依存
npm install maplibre-gl @turf/distance maplibre-gl-opacity maplibre-gl-gsi-terrain

# 開発依存（PWA）
npm install -D @vite-pwa/nuxt

# 開発依存（テスト）
npm install -D @nuxt/test-utils vitest @playwright/test
```

**注意**: `maplibre-gl-opacity` と `maplibre-gl-gsi-terrain` はVanilla JS向けのため、TypeScript型定義が不完全な可能性あり。`@ts-ignore` または手動型定義が必要になる場合がある。 🟡

### 4. `types/` ディレクトリ作成 🔵

**信頼性**: 🔵 *ユーザーヒアリング（types/index.ts一括定義選択）より*

```bash
mkdir types
```
