## 実装詳細

### 1. 本番ビルド実行 🔵

**信頼性**: 🔵 *REQ-001 + ビルド設定より*

```bash
npm run build
# .output/ または dist/ にビルド成果物が生成される
```

### 2. PWA動作確認 🔵

**信頼性**: 🔵 *REQ-080 + ユーザーヒアリングより*

```bash
npm run preview
# ブラウザのDevTools > Application > Service Workers で登録確認
# ブラウザのDevTools > Application > Manifest でmanifest確認
```

確認項目:
- [ ] Service Worker が registered/activated 状態
- [ ] manifest name: 防災マップ
- [ ] manifest display: standalone
- [ ] アイコン4種（192/256/384/512px）が確認できる

### 3. 全テスト実行 🔵

**信頼性**: 🔵 *REQ-090より*

```bash
# 単体テスト
npm run test:unit

# E2Eテスト（ビルド後に実行）
npm run test:e2e
```

### 4. モバイル確認 🟡

**信頼性**: 🟡 *NFR-201から妥当な推測*

Chrome DevToolsのDevice Toolbarでモバイル表示を確認:
- タッチ操作でマップ操作できる
- OpacityControlが操作できる
- ポップアップが適切なサイズで表示される
