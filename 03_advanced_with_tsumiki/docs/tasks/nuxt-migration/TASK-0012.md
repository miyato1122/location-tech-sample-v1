### 2. createApp マウントユーティリティ 🔵

**信頼性**: 🔵 *アーキテクチャ設計（createApp方式）より*

MapContainer.vue 内でShelterPopupをマウントするパターン：

```typescript
import { createApp } from 'vue'
import ShelterPopup from '~/components/ShelterPopup.vue'
import type { SkhbProperties } from '~/types'

export function mountShelterPopup(
  container: HTMLElement,
  properties: SkhbProperties,
  onClose: () => void
) {
  const app = createApp(ShelterPopup, { properties })
  app.mount(container)
  return { unmount: () => app.unmount() }
}
```
