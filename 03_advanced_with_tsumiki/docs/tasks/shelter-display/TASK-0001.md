## 実装詳細

### ベクトルタイル生成

Tippecanoe v2.9.1 を使用して国土地理院の指定緊急避難場所データ（GeoJSON/CSV形式）をPBF形式のベクトルタイルに変換。

**タイル仕様**:

| 項目 | 値 |
|------|-----|
| フォーマット | PBF（Protocol Buffers Binary Format） |
| ジオメトリ | Point |
| ズーム範囲 | 5〜8 |
| フィーチャー数 | 112,525件 |
| レイヤー名 | `skhb` |

**ディレクトリ構造**:

```
public/skhb/
├── metadata.json
├── 5/
│   ├── 27/
│   └── 28/
├── 6/
│   ├── 54/, 55/, 56/, 57/
├── 7/
│   └── 108-115/
└── 8/
    └── 216-231/
```

**属性定義**:

| 属性名 | 型 | 説明 |
|-------|-----|------|
| `name` | String | 施設名称 |
| `address` | String | 住所 |
| `remarks` | String | 備考（null あり） |
| `disaster1` | Boolean | 洪水 |
| `disaster2` | Boolean | 崖崩れ・土石流・地滑り |
| `disaster3` | Boolean | 高潮 |
| `disaster4` | Boolean | 地震 |
| `disaster5` | Boolean | 津波 |
| `disaster6` | Boolean | 大規模な火事 |
| `disaster7` | Boolean | 内水氾濫 |
| `disaster8` | Boolean | 火山現象 |
