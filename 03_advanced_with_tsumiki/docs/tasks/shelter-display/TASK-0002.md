## 実装詳細

### ベクトルタイルソース定義

```javascript
skhb: {
    type: 'vector',
    tiles: [`${location.href.replace('/index.html', '')}/skhb/{z}/{x}/{y}.pbf`],
    minzoom: 5,
    maxzoom: 8,
    attribution: '国土地理院:指定緊急避難場所データ',
}
```

`location.href` を動的に使用することでデプロイ先に依存しない実装。

### 8種レイヤーの共通定義パターン

```javascript
{
    id: 'skhb-N-layer',
    source: 'skhb',
    'source-layer': 'skhb',
    type: 'circle',
    paint: {
        'circle-color': '#6666cc',
        'circle-radius': ['interpolate', ['linear'], ['zoom'], 5, 2, 14, 6],
        'circle-stroke-width': 1,
        'circle-stroke-color': '#ffffff',
    },
    filter: ['get', 'disasterN'],  // 対応する disaster フラグ
    layout: { visibility: 'none' },
}
```

### レイヤーと災害種別のマッピング

| レイヤーID | フィルター | 対応災害 |
|-----------|----------|---------|
| `skhb-1-layer` | `disaster1` | 洪水 |
| `skhb-2-layer` | `disaster2` | 崖崩れ/土石流/地滑り |
| `skhb-3-layer` | `disaster3` | 高潮 |
| `skhb-4-layer` | `disaster4` | 地震 |
| `skhb-5-layer` | `disaster5` | 津波 |
| `skhb-6-layer` | `disaster6` | 大規模な火事 |
| `skhb-7-layer` | `disaster7` | 内水氾濫 |
| `skhb-8-layer` | `disaster8` | 火山現象 |
