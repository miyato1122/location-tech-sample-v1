### OpacityControl の設定

```javascript
const opacitySkhb = new OpacityControl({
    baseLayers: {
        'skhb-1-layer': '洪水',
        'skhb-2-layer': '崖崩れ/土石流/地滑り',
        'skhb-3-layer': '高潮',
        'skhb-4-layer': '地震',
        'skhb-5-layer': '津波',
        'skhb-6-layer': '大規模な火事',
        'skhb-7-layer': '内水氾濫',
        'skhb-8-layer': '火山現象',
    },
});
map.addControl(opacitySkhb, 'top-right');
```

- 配置: 地図右上（`top-right`）
- 機能: 8種の災害種別を排他的に切り替え（同時に1レイヤーのみ visible）
- 選択中レイヤーは `geolocation-routing/TASK-0002` の最近傍検索にも使用される
