# プロダクト概要

書籍「現場のプロがわかりやすく教える位置情報エンジニア養成講座」のサンプルアプリケーション。高度な地図機能を実演する位置情報アプリの実践編です。このディレクトリ（`04_advanced_with_cc-sdd`）は、Kiro スペック駆動開発（SDD）で管理されており、現在バニラ JS から Nuxt への移行を進めています。

## コア機能

- **ハザードマップオーバーレイ**: 洪水・高潮・津波・土石流・急傾斜・地滑りなど複数の災害ハザードレイヤーをベース地図に重ねて表示・切り替え
- **指定緊急避難場所の可視化**: 国土地理院の指定緊急避難場所をベクトルタイルで表示し、災害種別でフィルタリング可能
- **最寄り避難場所へのルート表示**: Turf.js を用いてユーザーの GPS 位置から最寄りの表示中避難場所までの直線ルートを描画
- **3D 地形表示**: 地理院標高タイルを raster-dem ソースとして利用し、陰影図と地形の立体表示を実現
- **PWA 対応**: Service Worker と Web App Manifest によるオフライン・モバイル利用

## 対象ユースケース

- 地図オーバーレイ・ベクトルタイル・位置情報 API を学ぶ位置情報エンジニア向けの参照実装
- スペック駆動開発によるフレームワーク移行（Nuxt 化）のサンプル

## 価値提供

入門チュートリアルと本番レベルの地図アプリの橋渡し。多くの汎用チュートリアルでは扱われない日本固有のデータソース（地理院タイル・ハザードポータル・避難場所データ）を具体的にカバーします。
